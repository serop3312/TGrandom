# TGrandom

В коде не забудьте добавить токен бота и ID Администатратора
PS: Для чайников
Как найти токен TG бота:
Найдите в поиске Telegram @BotFather. Важно: у нужного бота должна быть синяя галочка верификации, а в названии не должно быть лишних цифр или слов. 
Начните диалог, нажав «Запустить» (Start). В ответ BotFather пришлёт список доступных команд. 
Выберите команду /newbot. 

Укажите имя бота — оно будет отображаться у пользователей в списке чатов. Здесь можно использовать эмодзи. 
Задайте username (юзернейм). Он должен заканчиваться на bot (например, MyCoolBot), состоять только из латинских букв, цифр и подчёркиваний, и быть уникальным в системе. Если имя занято, BotFather попросит придумать другое. 
После успешной регистрации BotFather пришлёт сообщение со ссылкой на бота (в формате t.me/ваш_юзернейм) и токеном.

Как найти ID Администратора:
Откройте Telegram и в поиске введите @userinfobot.
Нажмите «Запустить» (Start) или отправьте /start.
Бот мгновенно пришлёт сообщение с вашим ID.
Windows

1. Клонирование репозитория 
```git clone https://github.com/serop3312/TGrandom```

2. Переход в директорию TGrandom
```cd TGrandom```

3. Создание виртуального окружения
```python -m venv venv```

4. Активация виртуального окружения
```.\venv\Scripts\activate```

5. Установка зависимостей
```pip install telebot```

6. Запуск скрипта для демонстрации возможностей
```python start.py ```
